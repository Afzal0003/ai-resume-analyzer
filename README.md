# AI Resume Analyzer

Full-stack project to analyze a resume against a job description using FastAPI, React, SQLite, and Gemini.

## Planned Features

- Upload resume PDF
- Extract text from PDF
- Paste job description
- Match percentage
- Missing skills detection
- Resume improvement suggestions
- Tailored resume summary
- Clean UI
- GitHub-ready structure
- Deployment on Vercel and Render

## Project Structure

- `backend/` FastAPI application
- `frontend/` React application
- `docs/` notes and roadmap

## Status

Core MVP is working locally:
- PDF upload
- PDF text extraction
- Job description input
- Gemini analysis
- SQLite history
